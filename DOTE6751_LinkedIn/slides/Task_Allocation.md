## 5. Working method

- **Reproducible builds.** One script rebuilds schema, seed, views, queries and audit
  (`build/build_all.py`); no artefact was produced by hand-editing the database.
- **Evidence over assertion.** Every number quoted in the documents traces to a CSV in
  `query_results/`.
- **Fail early.** The consistency audit and the fault-injection suite ran on every rebuild, so
  a schema change that broke an invariant was caught before it reached a document.
- **Two review passes.** A technical pass (does it run) and a narrative pass (does the claim
  match the result) on each artefact.
